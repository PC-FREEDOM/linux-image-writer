# Linux Image Writer

[English](README.md)

Linux 向けの、シンプルで安全性を重視した USB ディスクイメージ書き込みアプリです。

*Simple by default, powerful when needed.*

## 開発状況

Linux Image Writer は現在、最初の正式リリース(v0.1)に向けて開発中です。
現時点では正式な配布パッケージはありません。

## 機能

- ISO や IMG などの非圧縮ディスクイメージを書き込めます
- gzip / xz で圧縮されたイメージも、展開しながら書き込めます
- イメージの形式は、ファイル名だけでなくファイルの中身から判定します
- 書き込み先として選べるのは、書き込み可能な USB ドライブだけです。システムのドライブ、保護されているドライブ、使用中のドライブは選べません
- 書き込みの直前に、選択したドライブをもう一度確認します
- 書き込む前に、書き込み先のドライブを表示して最終確認を求めます
- 書き込み後の検証を選べます(クイック / 完全 / なし)
- 準備・書き込み・検証の進み具合を表示します
- 処理を途中で中止できます
- 処理の結果を結果画面にまとめて表示します
- 結果画面から、USB ドライブを安全に取り外せます(任意)
- GTK 4 と libadwaita による画面

### 含まれていないもの

- Linux 専用です
- パーティションの編集、ファイルシステムの作成(フォーマット)、persistence の作成はできません
- イメージのダウンロード機能はありません
- 書き込み前の自動アンマウントはしません。マウントされているドライブは、マウントを解除するまで選べません
- gzip / xz 以外の圧縮形式(zip、7z、bzip2、zstd、lz4 など)には対応していません

## 動作環境

- UDisks2 が動作している Linux
- polkit の認証エージェント(通常はデスクトップ環境に含まれています)

GUI は英語と日本語に対応しています。

## インストール

現時点では正式な配布パッケージはありません。
開発用ビルドのための本番用 Flatpak manifest は用意しています。アプリ本体のビルド方法は「[ソースからのビルド](#ソースからのビルド)」をご覧ください。

## 使い方

1. 書き込むイメージを選びます。
2. 書き込み先の USB ドライブを選びます。書き込める USB ドライブが 1 台だけ接続されている場合は、自動で選ばれます。
3. 検証方法を選びます。
4. 書き込みボタンを押します。
5. 最終確認で書き込み先のドライブを確かめて、承認します。システムの認証を求められる場合があります。
6. 書き込みと、選んだ場合は検証が終わるまで待ちます。途中で中止することもできます。
7. 結果を確認します。
8. 必要に応じて、結果画面から USB ドライブを安全に取り外します。

**書き込むと、書き込み先のドライブにある既存のデータはすべて消去されます。**

## 検証

- **クイック検証**は、書き込んだデータの一部を読み戻して確認します。速さと確認範囲のバランスをとった方法です。
- **完全検証**は、書き込んだデータをすべて読み戻して確認します。時間がかかります。
- **検証なし**では、読み戻しての確認を行いません。

gzip / xz で圧縮されたイメージでは、クイック検証は利用できません。完全検証か検証なしを選んでください。

## 安全な取り外し

書き込みが終わると、対応している USB ドライブについて、結果画面から取り外しの準備を行えます。これは自動では行われず、ユーザーが自分で実行します。必要に応じてドライブのファイルシステムのマウントを解除し、ドライブを取り外せる状態にします。「安全に取り外せます」と表示されるのは、これに成功した場合だけです。

対応していないドライブや、まだ使用中のドライブは、ファイルマネージャーやデスクトップ環境から取り外してください。

## 注意事項

- イメージを書き込むと、書き込み先のドライブにある既存のデータはすべて消去されます。
- システムのドライブや、保護されているドライブ、書き込み先に適さないドライブは、書き込み先として表示されません。
- 書き込みを始める前に、選択したドライブをもう一度確認します。
- 最終確認には書き込み先のドライブが表示されます。上書きしてよいドライブかどうかを確かめてください。
- 書き込み後の検証は任意です。

書き込みを承認する前に、意図したドライブを選んでいることを必ず確認してください。

## ソースからのビルド

必要なもの:

- Linux
- Rust 1.98.1(`rust-toolchain.toml` で固定しています)
- GTK 4.12 以降と libadwaita 1.5 以降(開発用ファイルを含む)
- pkg-config
- C コンパイラ
- 実行時: UDisks2 と polkit の認証エージェント

GUI のビルド:

```sh
cargo build --release --features gui --bin linux-image-writer
```

ビルドされたプログラムは `target/release/linux-image-writer` です。

リポジトリには、コマンドラインの開発・診断用ツール `linux-image-writer-dev` も含まれています。破壊的なテストモードを含むため、一般の利用は想定していません。
