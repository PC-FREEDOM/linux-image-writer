Linux Image Writer: licences of the Rust crates it is built from
================================================================

The Linux Image Writer program (linux-image-writer) is written in Rust and
is built with the Rust crates (libraries) listed below, which are compiled
into it. This file gives, for each crate, its version and licence, and then
the full licence texts, with the copyright notices the crates provide.

Where a crate offers a choice of licences (for example "MIT OR Apache-2.0"),
it is used here under the first of these that it offers: MIT; for the few
crates that need another licence as well, that licence is given with them.

Linux Image Writer itself is licensed under the GNU General Public License,
version 3 or later (see its LICENSE file). Libraries that are not Rust
crates, such as GTK and libadwaita, are not covered here: where a package
includes them, it gives their licences separately.

This file is generated by cargo-about from the project's Cargo.lock; see
build-aux/rust-licenses/ in the Linux Image Writer source.
