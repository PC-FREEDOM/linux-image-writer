# How the licences of the bundled Ubuntu packages are classified, and so which
# packages' corresponding source the AppImage's release carries. Read by
# check-appdir.sh, which writes the result into out/license-manifest.txt.
#
# A package's classes are taken from its copyright file (as installed by the
# package, usr/share/doc/<package>/copyright):
#   - machine-readable (DEP-5) files: every name in their "License:" fields,
#     split at "or", "and" and ",", with any "with ... exception" removed,
#     looked up in [names] below;
#   - other files: the [packages] entry below, written after reading the file,
#     and tied to its SHA-256.
# The build fails on a name or a file not reviewed here, and when a reviewed
# file changes, so a snapshot update cannot change a classification unseen.
#
# Classes:
#   GPL, LGPL, MPL, GFDL, CC-BY-SA   copyleft
#   permissive, public-domain        no copyleft
#   unreviewed                       not (yet) confirmed from the text
# Corresponding source is carried for every package with any class other than
# permissive or public-domain -- also when the copyleft licence is only one of
# several alternatives ("BSD or GPL-2+"), and when a name is unreviewed. This
# is deliberately on the safe side: it may carry more source than strictly
# required, never less.
